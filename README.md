# PolarisIQ - Legendary AI Sales & Meeting Assistant

> **Transform sales with deep AI intelligence and industry-specific skill packs**

PolarisIQ is a production-grade AI-powered sales and meeting assistant designed for serious professionals. Built with cutting-edge NLP, multi-model AI support, and deep industry knowledge packs that can be configured in minutes.

## 🌟 Key Features

### 🧠 **AI-Powered Intelligence**
- Multi-model AI support (GPT-4, Claude 3)
- Real-time conversation assistance
- Context-aware responses from uploaded materials
- Intelligent interjections and suggestions

### 🎯 **Deep Skill Packs**
Pre-built expertise for multiple industries:
- **Food & Beverage** 🍷 - Artisan products, wine pairing, specialty foods
- **Contractors** 🏗️ - Building materials, codes, estimation
- **Real Estate** 🏡 - Market analysis, valuation, negotiation
- **+ More** - Easily extensible to any industry

### 🎤 **Voice-Enabled**
- Hands-free operation during calls
- Real-time transcription
- Voice-activated suggestions

### 📁 **Context Upload Engine**
- Upload catalogs, pricing sheets, any document
- AI extracts and indexes everything
- Semantic search across all materials

### 🎥 **Meeting Intelligence**
- Recording and transcription
- Automatic meeting notes and action items
- Post-meeting insights and analysis

### 📊 **Analytics & Insights**
- Track performance and conversion rates
- Deal value monitoring
- Usage analytics

## 🚀 Quick Start

```bash
# Install dependencies
npm install --legacy-peer-deps

# Set up environment variables
cp .env.example .env.local

# Run development
npm run dev
```

Visit http://localhost:3000 to see the legendary landing page.
